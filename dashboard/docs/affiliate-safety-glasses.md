# ตัวอย่างงานแอฟฟิลิเอต: แว่นเซฟตี้ (ใช้คู่กับคลิปผีเฝ้าไซต์ EP.8)

> ตัวอย่างนี้ทำจากหมวดสินค้า ยังไม่ได้ผูกกับสินค้าจริง ช่องที่มีวงเล็บ [ ... ] ต้องเติมจากหน้าสินค้าจริงก่อนโพสต์ ห้ามเดาสเปกหรือราคา ส่งลิงก์สินค้ามาแล้วบ้านจะเติมให้ครบ

## ฮุก 3 วินาทีแรก (เลือก 1)
1. "ใส่แว่นกันแดดไปเจียรเหล็ก… รู้ไหมว่าเศษเหล็กอ้อมเข้าตาได้?"
2. "จป. ขอเตือน! แว่นกันแดดกันได้แค่แสง"
3. "แว่นเซฟตี้ราคาไม่ถึงค่าหาหมอตา" *(ใช้ได้เมื่อรู้ราคาจริงแล้วเท่านั้น)*

## สคริปต์ 30–40 วินาที
| ช็อต | ภาพ | คำพูด |
|---|---|---|
| 1 | ตัดจากคลิป EP.8 ฉากสะเก็ดไฟพุ่งเข้าหน้า | ใส่แว่นกันแดดไปเจียรเหล็ก… อันตรายกว่าที่คิด |
| 2 | การ์ดเทียบแว่นกันแดดกับแว่นเซฟตี้ (จาก EP.8) | แว่นกันแดดไม่มีที่กันด้านข้าง เศษเหล็กอ้อมเข้าตาได้ |
| 3 | ถือแว่นเซฟตี้จริง หมุนให้เห็นด้านข้าง | อันนี้แว่นเซฟตี้ [รุ่น] มีที่กันด้านข้าง เลนส์ [วัสดุ/มาตรฐานตามหน้าสินค้า] |
| 4 | ใส่แว่นแล้วครอบหน้ากากกันสะเก็ด | ถ้างานเจียร ใส่คู่กับหน้ากากกันสะเก็ดอีกชั้น |
| 5 | ชี้ตะกร้าเหลืองที่มุมจอ | ใครทำงานช่าง กดตะกร้าได้เลยครับ ราคา [ราคาจริง] |
